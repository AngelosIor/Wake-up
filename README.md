# Ημέρα Μου — Ξυπνητήρι, Πρόγραμμα, Αιμοδοσία & Ειδοποιήσεις

Ένα **μοναδικό αρχείο** (`index.html`) — δεν χρειάζεται τίποτα άλλο. Copy-paste στο GitHub όπως πάντα.

## Νέο: Αιμοδοσία (μέτρηση 90 ημερών)

Τέταρτη καρτέλα στο πάνω μενού. Πώς δουλεύει:

1. Καταχωρείς την ημερομηνία που έδωσες αίμα.
2. Η εφαρμογή μετράει **90 μέρες** και σου δείχνει πόσες μέρες απομένουν (με μπάρα προόδου) — τόσο στη σελίδα της Αιμοδοσίας όσο και σε συντόμευση στην Αρχική.
3. Όταν περάσουν οι 90 μέρες, παίρνεις **ειδοποίηση** "Μπορείς να ξαναδώσεις αίμα!" και εμφανίζεται ένα μήνυμα στη σελίδα.
4. Αν δεν καταχωρήσεις αμέσως νέα δωρεά, μπορείς να πατήσεις **"Θύμισέ μου σε 1 μέρα"** — και μετά από 24 ώρες θα πάρεις ξανά ειδοποίηση **"Έδωσες αίμα;"**, ξανά και ξανά κάθε μέρα, μέχρι να καταχωρήσεις τη νέα δωρεά.
5. Μόλις καταχωρήσεις μια νέα ημερομηνία δωρεάς, η μέτρηση ξεκινάει από την αρχή.

Η ημερομηνία μένει αποθηκευμένη στη συσκευή σου όπως όλα τα υπόλοιπα (localStorage).

## Τι άλλαξε σε προηγούμενη παράδοση

**1. Το bug που ανέφερες ("δεν μπορούσα να προσθέσω κάτι στο πρόγραμμα") — διορθώθηκε στη ρίζα του:**
- Αφαιρέθηκε τελείως το ξεχωριστό πεδίο ημερομηνίας (που υπολογιζόταν με UTC ώρα αντί για τοπική — κοντά στα μεσάνυχτα μπορούσε να δείξει λάθος μέρα). Τώρα διαλέγεις μέρα από μια **γραμμή εβδομάδας** στην κορυφή, σαν το Google Calendar.
- Το πεδίο "Ώρα" (που ήταν υποχρεωτικό αλλά έμενε κενό, μπλοκάροντας σιωπηλά την υποβολή) **συμπληρώνεται τώρα αυτόματα** με την τρέχουσα ώρα, τόσο στα Ξυπνητήρια όσο και στο Πρόγραμμα. Δεν χρειάζεται να θυμάσαι να το γεμίσεις.

**2. Το Πρόγραμμα έγινε σαν το Google Calendar** (αυτό σου το χρωστούσα από παλιότερο μήνυμα — δεν σου το είχα παραδώσει ακόμα):
- Γραμμή 7 ημερών στην κορυφή, με σημερινή μέρα τονισμένη και βελάκια για προηγούμενη/επόμενη εβδομάδα.
- Για κάθε εργασία ορίζεις: τίτλο, ώρα έναρξης, **διάρκεια** (15΄ έως 2 ώρες) — η ώρα λήξης υπολογίζεται και εμφανίζεται αυτόματα.
- **Τικ ολοκλήρωσης** — πατάς το κυκλάκι όταν τελειώσεις, η εργασία παίρνει διαγράμμιση.
- **Χρονόμετρο ανά εργασία** — πατάς "⏱ Χρονόμετρο" όταν ξεκινάς, μετράει αντίστροφα, και όταν φτάσει το 0 χτυπάει σαν ξυπνητήρι (ίδια αξιόπιστη οθόνη/ήχος) λέγοντας "Ώρα να τελειώσεις: [τίτλος]".
- **Ειδοποιήσεις** (προαιρετικές, με ένα checkbox) — μία όταν έρχεται η ώρα να ξεκινήσεις (πόσα λεπτά πριν διαλέγεις εσύ), και μία αυτόματα όταν φτάνει η υπολογισμένη ώρα λήξης, να σου θυμίσει να τελειώσεις.

**3. Το ζητούμενο design polish** — πάνω σε όλη την εφαρμογή (Αρχική, Ξυπνητήρια, Πρόγραμμα), χωρίς να αλλάξει καμία λειτουργία:
- Πιο μοντέρνα cards, κουμπιά και πεδία εισαγωγής, με καλύτερο spacing.
- Το navigation στην κορυφή πήρε εικονίδια και ένα διακριτικό gradient στην ενεργή καρτέλα.
- Διατηρήθηκε η χρωματική ταυτότητα navy/teal/gold — μοντερνοποιήθηκε με ένα απαλό gradient (navy→teal→gold) στα βασικά κουμπιά, στην ενεργή πλοήγηση, και στο ρολόι, χωρίς να προστεθεί κανένα άλλο χρώμα.
- Διακριτικά animations: απαλή μετάβαση όταν αλλάζεις σελίδα, ήπιο "φούσκωμα" στην οθόνη ξυπνητηριού, ελαφρύ hover/press effect σε κάρτες και κουμπιά.
- Πιο καθαρές λίστες ξυπνητηριών/εργασιών με καλύτερο διαχωρισμό.

## Πώς το ανεβάζεις στο GitHub (ίδια διαδικασία με πριν)

1. [github.com](https://github.com) → **New repository** → όνομα π.χ. `mera-mou` → **Create repository**.
2. **Add file → Upload files** → ανέβασε **μόνο το `index.html`** → **Commit changes**.
3. **Settings → Pages** → Source: branch **main**, folder **/ (root)** → **Save**.
4. Μετά από 1-2 λεπτά θα έχεις link: `https://<username>.github.io/mera-mou/`

## Πώς το κάνεις να μοιάζει με εφαρμογή στο κινητό

Άνοιξε το link στο κινητό → μενού browser → **"Προσθήκη στην αρχική οθόνη"** → άνοιξέ το από το νέο εικονίδιο → **"Ενεργοποίηση ειδοποιήσεων"**.

## ⚠️ Ό,τι ίσχυε και πριν, ισχύει ακόμα

- Η σελίδα πρέπει να μένει ανοιχτή (έστω στο background) για να χτυπήσουν τα ξυπνητήρια/χρονόμετρα/ειδοποιήσεις. Αν το κινητό «σκοτώσει» εντελώς την εφαρμογή, δεν θα λειτουργήσουν.
- Ο δικός σου ήχος για ξυπνητήρι χρειάζεται άμεσο link προς αρχείο ήχου (.mp3/.wav/.ogg) — YouTube/Spotify δεν δουλεύουν έτσι, οπότε πέφτει αυτόματα πίσω στον προεπιλεγμένο ήχο.

## Τι ελέγχθηκε

**94 αυτοματοποιημένα τεστ σε πραγματικό browser, όλα περνάνε** — 76 από πριν (ξυπνητήρια, πρόγραμμα, διάρκεια χτυπήματος, ήχος, σελίδες) + **18 καινούρια ειδικά για την Αιμοδοσία**: καταχώρηση δωρεάς, σωστή μέτρηση 90 ημερών, ειδοποίηση όταν έρχεται η ώρα (ακριβώς μία φορά, όχι επαναλαμβανόμενα), το κουμπί αναβολής, η επαναλαμβανόμενη ερώτηση "Έδωσες αίμα;" κάθε 24 ώρες μέχρι να απαντήσεις, επαναφορά της μέτρησης όταν καταχωρείς νέα δωρεά, και διατήρηση μετά από reload.

Στην πορεία βρήκα και διόρθωσα δύο ακόμα πράγματα πριν σου το στείλω: το μπάνερ "μπορείς να ξαναδώσεις" έμενε ορατό ακόμα και μετά το "θύμισέ μου αργότερα" (τώρα κρύβεται σωστά μέχρι να περάσει η ώρα)· και με 4 καρτέλες στο μενού, σε στενές οθόνες κινητού η τελευταία καρτέλα έκοβε — τώρα σε μικρές οθόνες το μενού δείχνει μόνο εικονίδια (χωρίς κείμενο) ώστε να χωράνε άνετα και οι 4.

Αν κάτι δεν δουλέψει όπως περιμένεις ή κάτι στο design δεν σου αρέσει, πες μου ακριβώς τι είδες.
